全部计算由浏览器内嵌的 Python + NumPy 完成（Pyodide / WebAssembly）。
勾选「自动标定电极帽 TCP」时改用 9 参数模型 R·base + t = rob + Rtool·c：由 A/B/C 姿态还原每点工具坐标系， 用多起点 Gauss-Newton / LM 同时解出 R、t 与工具偏移 c （与 WcsCal 等收费软件同一模型），残差按「实际触点」计算。
